## 摘要
校验**思澈所有带音频 ADC 的 MCU**（已导入 SF32LB52X/x、SF32LB57X/x 等，且为全系通用输入规范）音频 ADC 模拟输入（单端 ADCP、差分 ADCP/ADCN）的前端电路：单端/差分隔直电容接法、输入满幅（Vpp）随增益变化的范围、IO 耐压上限、以及音频信号地与芯片地共地。适用于原理图 AI 审图与硬件评审。

> **适用范围说明**：本条为思澈（SiFli）音频 ADC 的**全系通用输入规范**，凡带音频 ADC 的芯片均适用；下方 `mcu_family` 仅列出本知识库已导入并确认含音频 ADC 的家族（SF32LB52、SF32LB57），新增家族时依规同样适用。

## 核心硬件内容（背景）
- 音频 ADC 为 24-bit，支持**单端**（仅 P 端输入，N 端可作普通 GPIO）与**全差分**（P/N 双端输入）麦克风；模拟增益可调（典型 ‑6~+18dB，6dB/step，依具体型号）。
- 输入为**交流耦合**：须串联隔直电容，阻断前后级直流偏置。
- **输入满幅（Vpp）随增益变化**：增益越高，允许输入幅度越小（幅度上限 = 基准 / 增益(线性比)）。
- **IO 耐压 3.3V，绝对最大 3.63V**（超过即 IO 损伤风险，等同 [[CR_AbsMaxRatings]] 的 AbsMax 违规）。
- 音频为小信号模拟，信号地须与芯片模拟地**可靠共地**，以保证参考一致、抑制共模噪声与哼声。

## 专项业务内容 —— 原理图 AI 审图规则（必填）

### 规则 A：音频 ADC 输入隔直电容（单端 / 差分）
1. **判定条件**：解析到音频 ADC 输入引脚（如 ADCP；差分对 ADCP/ADCN）前端网络时触发。
   - 单端用法：仅 **P 端**须串联 **≥2.2µF** 隔直电容；**N 端不使用，作普通 GPIO**（确认 N 端未被当作信号输入、无隔直电容误接，也勿悬空成天线）。
   - 差分用法：**P 端与 N 端各须串联 ≥2.2µF** 隔直电容。
2. **违规现象描述**：音频 ADC 输入未串隔直电容，或容值 <2.2µF；单端模式 N 端被误接为信号输入或悬空；差分模式仅一端有隔直电容。
3. **风险影响说明**：直流偏置进入 ADC → 饱和/削波、输入共模错误；隔直不足引入低频失调与开机砰声（pop）（一般级性能风险）。
4. **标准化整改方案**：按单端/差分补齐 2.2µF 隔直电容（推荐低漏电 MLCC，注意直流偏压降额）；单端 N 端按 GPIO 处理（可 NC 或配置为普通 IO）。
5. **知识库溯源依据**：[[CR_Checklist_Audio]]（多媒体-音频 第 5 条）；本条为其细化的输入规范。

### 规则 B：音频 ADC 输入幅度范围（与增益关系）
1. **判定条件**：评审确认麦克风/信号源最大输出幅度与所选 ADC 增益组合。
   - **单端（0dB）**：允许输入 Vpp = **±0.68V**；其他增益下 Vpp = **±0.68V / 增益(线性比)**。
   - **差分（0dB）**：允许输入 Vpp = **±1.35V**；其他增益下 Vpp = **±1.35V / 增益(线性比)**。
2. **违规现象描述**：信号源满幅超过对应增益下的 Vpp 上限（如单端 0dB 接入 >±0.68Vpp 信号）→ 削波失真。
3. **风险影响说明**：ADC 削波、THD+N 恶化、录音失真（一般级性能风险）。
4. **标准化整改方案**：按信号源幅度选择增益（增益↑ → 允许输入↓），必要时前端加衰减；确认增益档位与信号幅度匹配。
5. **知识库溯源依据**：思澈音频 ADC 通用输入规范（见原始来源）；待补各型号 datasheet 电气表原文。

### 规则 C：音频 ADC 输入 IO 耐压
1. **判定条件**：解析音频 ADC 输入引脚前端网络的最高直流/峰值电压。
2. **违规现象描述**：输入节点电压超过 3.3V 额定耐压 / 3.63V 绝对最大（如单端耦合后峰值 >3.63V、或麦克风偏置耦合异常抬升）。
3. **风险影响说明**：超过 IO 绝对最大额定值 → IO 永久损伤（**严重级**，与 [[CR_AbsMaxRatings]] 同判）。
4. **标准化整改方案**：确保隔直后信号峰峰值不突破 3.63V（考虑直流偏置与信号叠加）；必要时前端限幅/衰减。
5. **知识库溯源依据**：IO 耐压 3.3V / 绝对最大 3.63V（通用 IO 约束，见 [[CR_AbsMaxRatings]]）。

### 规则 D：音频信号地与芯片地共地
1. **判定条件**：审图确认音频输入回路（麦克风/信号源地）与芯片 GND / 模拟地（AGND）连接关系。
2. **违规现象描述**：音频信号源地与芯片地未连通（浮地）；或共地点远、走线细导致地弹/共模噪声。
3. **风险影响说明**：参考不一致 → 噪声、哼声（hum）、共模干扰、ADC 性能下降（一般级）。
4. **标准化整改方案**：音频信号源地与芯片模拟地**单点/低阻可靠共地**，保证模拟地完整回流。
5. **知识库溯源依据**：模拟前端共地设计通则。
