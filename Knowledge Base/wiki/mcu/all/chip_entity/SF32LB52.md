## 摘要
**SF32LB52** 是 SiFli（思澈科技）面向 AIoT 的超低功耗双核 MCU **52 家族**。本家族包含 **两个独立系列，不能合并视为一个芯片系列**：

- **SF32LB52X（大写 X）= 3.3V 供电系列**：**无充电电路**，主电源专用引脚为 **PVDD（1.8/3.3V）**，GPIO 由 **VDDIOA** 供电，型号 52B / 52D / 52E / 52G / 52J。由 **DS5202-SF32LB52X V0.2.6** 描述。
- **SF32LB52x（小写 x）= 电池供电系列**：内置 560mA 锂电线性充电器，电源专用引脚为 **VBUS / VBAT / VSYS / VCC**，型号 520 / 523 / 525 / 527（+LUB6）。由 **DS5201-SF32LB52x V2.5.5** 描述。

两系列共用的部分（双核 Cortex-M33 STAR-MC1、576KB SRAM、存储架构、外设逻辑、GPIO 复用矩阵 PA00–PA44、双模 BT5.3、调试接口等）基本一致（**仅 PA21 不同：仅 3.3V 系列有 PA21，电池系列无 PA21、共 44 GPIO；3.3V 系列共 45 GPIO**）；**本质区别在电源架构与电源专用引脚定义**（详见 [[SF32LB52_Peripheral_Power]]、[[SF32LB52_Peripheral_GPIO]]）。两系列 **共用同一份用户手册 UM5201 V0.8.8**。

> 📌 **文档命名一致性**：原厂文档标题大小写与本家族芯片系列**一致**——
> - 3.3V 系列（大写 X）写在 **DS5202-SF32LB52X**（标题大写 X）；
> - 电池系列（小写 x）写在 **DS5201-SF32LB52x**（标题小写 x）。
>
> 判定依据为文档**内容**：仅 DS5201 含「560mA 锂电充电 / VBUS / VBAT」；DS5202 仅 PVDD、无充电电路、VBATS 仅为测量输入。知识库一律以**芯片系列命名（X=3.3V / x=电池）**为权威，与文档标题大小写一致。

## 两个系列关键对比
| 维度 | SF32LB52X（3.3V，大写 X） | SF32LB52x（电池，小写 x） |
|------|------|------|
| 主电源专用引脚 | PVDD(19,in) | VBUS(21,in) / VBAT(20,out) / VSYS(19,out) / VCC(24,in) |
| 电池测量 | VBATS(20) 电池电压测量输入（0~4.7V） | VBAT 即电源输出 |
| 充电电路 | 无 | **内置 560mA 锂电线性充电**（Vcv 4.2~4.45V） |
| 工作主电压 | 1.8V 或 3.3V（PVDD，随型号） | 锂电 3.2~4.7V（VBAT/VCC） |
| 典型型号 | 52BU36 / 52BU56 / 52DUB6 / 52EUB6 / 52GUC6 / 52JUD6 | 520U36 / 523UB6 / 525UC6 / 527UD6 / 523LUB6 |
| 来源文档 | DS5202-SF32LB52X V0.2.6 | DS5201-SF32LB52x V2.5.5 |
| GPIO 数量 | 45（含 PA21） | 44（无 PA21，pin24 为电源引脚 VCC） |

> **引脚定义差异范围（已确认）**：两系列**仅引脚 19~24 与引脚 14 的引脚定义不同**，其余引脚（PA00–PA44 GPIO 复用矩阵）**基本一致，唯一例外是 PA21**：PA21 仅存在于 3.3V 系列（pin24=PA21）；电池系列 pin24 为电源引脚 VCC、**无 PA21**，故 **3.3V 系列共 45 GPIO、电池系列共 44 GPIO**。差异集中在电源/充电专用引脚（19 PVDD↔VSYS、20 VBATS↔VBAT、21 VDDIOA↔VBUS、22/24 对应电源输出、23 VDD_SIP↔VDD18_VOUT、14 AVDD33↔VDD33_VOUT2）。
> **IO 驱动能力两系列完全相同（已确认）**：`12/30/38mA`（测试条件 VOH=0.8×VDDIO）与 `2/4/8/12mA`（测试条件 VOH=0.9×VDDIO）是同一驱动电路在两种输出高电平测试条件下的结果，并非不同能力。
