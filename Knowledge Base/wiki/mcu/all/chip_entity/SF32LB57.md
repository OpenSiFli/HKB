## 摘要
**SF32LB57 家族**为 SiFli（思澈科技）面向 AIoT / 智能穿戴的超低功耗多核 MCU 系列，与 SF32LB52 家族同样**分为两个独立供电系列**：

| 系列 | 芯片命名 | 供电方式 | 描述文档 | 实体页 |
|---|---|---|---|---|
| **3.3V 供电系列** | `SF32LB57X`（**大写 X**） | 外部 3.3V 稳压供电（PVDD），**无充电电路** | DS5702-SF32LB57X-CN | [[SF32LB57X]] |
| **电池供电系列** | `SF32LB57x`（**小写 x**） | 锂电池供电，**内置充电模块**（VBUS/VBAT/VCC/VSYS） | DS5701-SF32LB57x-CN | [[SF32LB57x_batt]]（别名 SF32LB57x） |

> 📌 **判定规则（与 SF32LB52 家族完全一致）**：以**芯片命名大小写**判定系列——**大写 X = 3.3V 系列，小写 x = 电池系列**；文档标题大小写与芯片命名**一致，不存在反转**。
>
> 📌 **NTFS 陷阱**：Windows 不区分大小写，同目录下 `SF32LB57X.md` 与 `SF32LB57x.md` 是**同一文件**。故电池系列实体页必须带 `_batt` 后缀，引用写作 `[[SF32LB57x_batt|SF32LB57x]]`。

## 家族共享规格（两系列一致）
- 内核：**双 Arm Cortex-M33 STAR-MC1 @240MHz**（HPSYS 双性能核），**1968 CoreMark**
  - HCPU：32KB(2-way) I-Cache + 16KB(4-way) D-Cache
  - ACPU：16KB(2-way) I-Cache + 8KB(4-way) D-Cache
  - HPSYS SRAM **512KB**（全部 Retention）；LPSYS Cortex-M33 @24MHz + SRAM **80KB**（全部 Retention）→ 合计 **592KB**
  - 单精度 FPU、MPU；功耗效率 **23µA/MHz @3.8V**
- 图形：2D/2.5D **ePicasso 3.0** 引擎（旋转/缩放/投影/镜像硬件加速，最大 2048×2048，RGB888/RGB565、aRGB8888/aRGB8565、L8/4、G8/4/2、A8/4/2、YUV，多种 alpha 混叠）；**eZip 3.0** 解压加速器（eZip/eZip-A 无损、JPEG/MJPEG 有损，可与 ePicasso 联动免中间缓存）
- 显示：内置 LCD 控制器，支持 **8080 / SPI·Dual-SPI·Quad-SPI / DPI(RGB) / JDI / 8-16b EPD**，不依赖 CPU 自主实现最高 60fps 全屏刷新，支持低功耗息屏常显；DCMI 摄像头（DVP / SPI 系列）
- 无线：**双模蓝牙 6.3**（支持 BLE Audio、LE LR）
  - 灵敏度：**‑100dBm（BLE 1Mbps）**、‑107.5dBm（BLE S8/125Kbps）、‑96dBm（BR）、‑95dBm（EDR2）
  - 最大发射功率：**17dBm（BR/BLE）**、13dBm（EDR2/3）；接收峰值功耗 2.0mA@3.8V（BR）
- 音频：1× 高保真 **24-bit DAC**（Noise floor 3.7µVrms、SNR/DR 109dB@10kΩ A-weighted、输出摆幅 1.1Vrms、采样 8~96kHz、192 级数字音量带过零检测）；**2× 24-bit ADC**（SNR 97dB A-weighted、输入电阻 23kΩ、增益 ‑6~+18dB/6dB 步进、数字高通滤波去直流、支持单端与全差分麦克风）；**Micbias LDO 1.4~2.8V / 0~2mA**
- 存储接口：SiP NOR-Flash ≤**104MHz**(DTR)、SiP OPI-PSRAM ≤**156MHz**(DDR)；**3× MPI(QSPI)**（NOR / NAND / QPI-PSRAM，外挂 ≤104MHz SDR）；**2× SD/SDIO**（SD3.0 / SDIO3.0 / eMMC，48MHz）
- 连接外设：**58 GPIO + 6 GPO MPI IO**；FreeIO GPIO 灵活配置；**3× UART、4× I2C、2× SPI、2× I2S、2× PDM、1× USB2.0 FS、2× CAN**；GPDMA（链表模式）；PTM 外设任务控制器
- 模拟：**1× 12-bit SAR ADC，12 通道，4Msps**；1× 片上温度传感器
- 定时器：2×16b GPTIM、4×32b BTIM、2×32b ATIM、2×24b LPTIM、1× PWM、1× RTC、2×24b WDT、1× IWDT
- 安全：AES / HASH / CRC 加速器、TRNG、eShield 安全架构、**PSA Certified Level 1**
- 电源管理：内置高效率 **Buck** + 低功耗 **LDO**；**休眠功耗（特性页宣称，Table 4-6 全 TBD 待核实）：3.3V 系列 1µA@3.3V、电池系列 2.8µA@3.8V**
- 工作温度：**‑40 ~ +85 °C**

## 两系列差异总览（核心）
**差异仅在电源架构与电源专用引脚**，其余（双核、SRAM、外设逻辑、GPIO 复用矩阵、BLE、射频、音频、晶体、GPADC）基本一致。

| 对比项 | SF32LB57X（3.3V） | SF32LB57x（电池） |
|---|---|---|
| 主电输入 | **PVDD**(19)，接 3.3V 电源 | **VCC**(24)，接电池 |
| 充电 | **无充电电路** | **内置充电模块**，VBUS(21) 输入 |
| 电池接口 | VBATS(20) 仅**电压检测** | **VBAT**(20) 电源输出接电池（内含 ADC 检测） |
| 系统电源输出 | — | **VSYS**(19) 3.0V 输出 |
| GPIO 电源 | **VDDIOA**(21) 独立 IO 域 | 无独立 VDDIOA 引脚（IO 域由内部供给） |
| 对外 3.3V 输出 | — | **VDD33_VOUT1**(22) / **VDD33_VOUT2**(14)，各 **150mA** |
| 模拟电源 | **AVDD33**(14) 外部 3.3V 输入 | 无独立 AVDD33（内部产生） |
| 射频电源 | AVDD_BRF(52) 接 **3.3V** | AVDD_BRF(52) 接 **VSYS** |
| 封装 | QFN68 / **QFN80** / **BGA112** | 订购信息仅列 **QFN68**（DS5701 详述 QFN80/BGA112 管脚与封装，但 Table 6-1 缺失其料号，属规格书缺陷） |
| GPIO 数（QFN68） | 47 | 比 3.3V 少 1（pin24 被 VCC 占用，待确认） |

**同封装（QFN68）引脚差异对照**
| 引脚 | 3.3V 系列 | 电池系列 |
|---|---|---|
| 14 | AVDD33（模拟电源输入 3.3V） | VDD33_VOUT2（3.3V LDO2 输出 150mA） |
| 19 | PVDD（PMU 电源输入 3.3V） | VSYS（电源输出 3.0V） |
| 20 | VBATS（电池电压检测输入） | VBAT（电源输出，接电池） |
| 21 | VDDIOA（GPIO 电源输入） | VBUS（充电模块电源输入） |
| 22 | NC（无信号） | VDD33_VOUT1（3.3V LDO1 输出 150mA） |
| 24 | GPIO（非专用脚） | VCC（系统电源输入，接电池） |
| 52 | AVDD_BRF（接 3.3V） | AVDD_BRF（接 VSYS） |

## 待核实问题
1. 两份规格书均为 **V0.2 草稿**，`Table 4-5 处理器功耗`、`Table 4-6 BT/BLE 功耗` **全部 TBD**，功耗预算无法核算。
2. 两册 `Table 4-1/4-2` 均同时列出 VBUS/VBAT/VCC 与 PVDD、`Table 4-20` 充电模块特性——**这是芯片裸 die 同时支持电池与 3.3V 两种供电模式的完整能力描述，非草稿误植**（规格书多处明确）。QFN68 3.3V 封装未将 VBUS/VBAT/VCC 引出到封装引脚（pin19/21/22 = PVDD/VDDIOA/NC），故 3.3V QFN68 版本按引脚表布线、不接充电电路；**布线以引脚表为准**。详见来源页一致性核查报告。
3. 两册均含 `Table 4-20 充电模块电气特性`：充电模块为 die 共用内置功能，3.3V QFN68 封装未引出 VBUS/VBAT 引脚，故 3.3V 版本无需连接。
4. 尚未导入用户手册（UM）与硬件设计指南，BOOT/nRST 外部电路、PCB 布局、EMC/ESD 规范缺失。
5. 电池系列 GPIO 确切数量待确认；DS5701 已详述 QFN80/BGA112 管脚与封装，但 Table 6-1 订购信息仅列 QFN68 料号（QFN80/BGA112 料号缺失，属规格书【严重】缺陷，见一致性核查报告），非"后续提供"。
