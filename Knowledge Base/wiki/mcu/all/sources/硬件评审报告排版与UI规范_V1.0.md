## 摘要
公司级《硬件评审报告排版与 UI 规范 V1.0》（2026-10-16 发布），与《硬件评审报告编制规范 V1.0》配套，规定评审报告（Word / PDF 阅读版）与评审工作台网页界面的视觉参数、信息层级、组件与交互行为。本页为来源摘要，**是 `wiki/mcu/all/report_template/_template.md` 的权威依据**；报告模板与该规范冲突时以本规范为准。

适用范围：Word 报告、PDF 阅读版、网页评审界面（UI 指评审工作台，不涉及被评审产品本身的屏幕）。

## 核心要点（转化为报告模板的关键条款）

### 1. 统一原则
- **三类状态必须分开**（§1.1）：
  - 等级（影响多大）：**P0 / P1 / P2**；不回答证据是否充分。
  - 事实状态（判断到哪一步）：**确认缺陷 / 待验证风险 / 改进建议**。
  - 处理状态（工作到哪一步）：**新建 / 处理中 / 已修改待复审 / 已关闭 / 重新打开 / 风险接受 / 误报撤销**。
  - Checklist 另用：**通过 / 不通过 / 待验证 / 不适用 / 未评审**；不能把问题处理状态直接套给 Checklist。
- **避免视觉误导**（§1.2）：P0 标签后必须同时显示事实状态；绿色仅用于有证据的通过或已关闭，风险接受/误报撤销用中性色；不用整页红底制造严重感；不使用"总分 95 分"等未定义评分替代阶段结论。

### 2. 文档页面与字体（§2，Word/PDF）
- 纸张 A4 竖向 210×297mm；页边距 上下 17mm、左右 18mm，竖向正文净宽 **174mm**；宽表允许单独 A4 横向分节。
- 字体：中文+西文默认**微软雅黑**（缺字回退已检查 CJK）；PDF 须检查字体嵌入/合法子集。
- 字号字重（pt）：Title 22 加粗 / H1 16 加粗 / H2 12 加粗 / 正文 10.5 / 表格 9.2 / 图注 8.5 / 页脚 8。
- 技术名词保留原写法（PA31 不写 PA_31，µF 与 nF 不混用）；数值与单位尽量不跨行。

### 3. 表格 分页与信息密度（§3）
- 表头背景 **#E3EDF3** 黑字加粗；正文行 白 / **#F6F8FA** 交替；边框 **#D9D9D9** 0.5pt；单元格内边距约 1.5mm；表宽 ≤174mm；**续页必须重复表头**。
- **问题总表建议 5 列**：ID 23mm ／ 等级与事实状态 34mm ／ 位置与问题简述 43mm ／ 处理与负责人 46mm ／ 状态 28mm（合计 174mm）。长证据/计算/影响移入问题详情，用问题 ID 关联。
- 分页：标题与至少两行正文或首条记录同页；图片与图注同页；单条超页拆成详情或续表，不靠禁止跨页造成截断；优先顺序 删重复→调列宽→拆总表与详情→横向分节；表格不小于 9pt。

### 4. 原理图证据与数据图（§4）
- 来源须记录原始 PDF/EDA 导出的文件 ID、版本、页码；优先矢量，位图用 PNG 且**有效分辨率 ≥300ppi**（144mm 宽约需 1701 像素）。
- **标注语义**：红色只指向已确认异常；待核实连接用琥珀色框+"待核实"文字；蓝色用于路径/参考定位。标注旁写问题 ID，原图 EDA 导线颜色保持不变。
- 四线交叉须看清连接点；**UART 路径须同时展示器件实际 TXD/RXD 引脚、中间电阻、网络标签与对端引脚**；仅截取网络名不能证明接线错误。
- 数据曲线须标坐标/单位/测试条件/样品版本/来源；判定上下限线注明来源；不裁掉关键峰值/异常区间/改刻度强化结论。

### 5. 颜色与语义变量（§6，网页/状态）
- 阻断或错误 **#B42318**（P0/不通过）/ 警示与待验证 **#854A0E**（P1/关键待验证）/ 信息与进行中 **#175CD3**（P2/处理中）/ 通过与已关闭 **#166534**（真实通过或验证关闭）/ 中性与例外 **#475467**（未评审/不适用/接受风险/误报撤销）。
- "已修改待复审"用信息色或中性，不能变绿；"风险接受""误报撤销"用中性，不能以绿勾冒充验证关闭。

### 6. 网页界面（§5/7/8，评审工作台，非本报告模板强制项）
- 信息架构：项目概览/输入与依据/问题台账/逐页检查/Checklist/GPIO与电源/验证计划/复审记录/报告导出；首屏显示项目、材料版本、阶段结论、关键待验证数、未关闭问题数。
- 配套样例 `review-ui.html`、`review-tokens.css`（离线样例，仅演示信息结构与组件，无保存/签核/发布功能）。**当前 vault 尚未纳入这两个文件**，如启用网页评审工具需另行引入。
- 无障碍：键盘可达、焦点环 3px；项目控件点击区默认 ≥44×44 CSS px（≠ WCAG 2.2 SC 2.5.8 的 24px 最低值）；视口验收 1440/1024/768/390/320px 无横向溢出。
