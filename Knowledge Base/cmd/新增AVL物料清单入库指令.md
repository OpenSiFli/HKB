# AVL合格物料清单表格结构化入库指令提示词
## 前置约束
1. 当前Obsidian Vault已搭建企业全系列MCU硬件知识库，根目录`AGENTS_MCU_ALL.md`为最高运维规范，全部操作严格遵循文件所有条款；
2. 待导入文件路径：【替换AVL表格完整raw路径，示例：raw/mcu/vendor/device_spec/MCU配套AVL合格物料清单_V2026.xlsx】
3. 文档类型：企业AVL合格物料表，Excel/CSV格式，包含MCU配套电源、晶振、电阻电容、复位芯片、驱动、连接器、ESD器件等所有外围元器件，字段包含料号、厂商、规格参数、封装、额定参数、适配MCU型号、认证状态、替代料、禁用物料、温区等级、安规等级、价格批次限制等；
4. 文档定位：企业唯一合规物料选型基准，优先级高于器件原厂规格书，原理图审图物料校验最高判定依据。

1. 完整解析AVL表格所有物料条目，按器件类型、适配MCU系列/型号结构化入库；

4. 区分推荐物料、备选替代物料、受限物料、禁用物料，分级标注风险；

6. AVL物料参数与器件datasheet冲突时，以AVL企业标准为准，同时保留原厂参数并标注优先级差异。

## 二、全维度提取拆解范围
### 1. AVL表格基础元数据（来源页全局记录）
表格版本、生效日期、适用MCU产品线、物料准入标准、认证要求（AEC-Q100/安规/环保）、物料淘汰规则、变更审批规范。

### 2. 元器件实体完整信息（更新wiki/mcu/all/entities/）
覆盖MCU所有外围配套器件：LDO/DC-DC电源、无源器件（R/C/L）、晶振、复位IC、电平转换、ESD/TVS、驱动芯片、接插件、存储芯片等；
每条物料提取字段：
1）企业内部料号、原厂料号、厂商品牌；
2）电气关键参数：额定电压、电流、功率、容值/阻值、频率、驱动能力；
3）封装尺寸、贴片规格、温度工作区间；
4）适配MCU系列、具体芯片型号、适用硬件模块（最小系统/ADC/CAN/PWM等）；
5）替代物料清单、唯一替代/多备选；
6）物料分级：优先推荐、备选替代、受限使用、永久禁用；
7）量产限制：批次限制、交期风险、成本限制、环保RoHS合规状态。

### 3. MCU各模块物料选型规范（补充wiki/mcu/all/peripheral/、design_rules）
1. MCU最小系统标准物料：电源芯片、复位、晶振、退耦电容统一AVL型号；
2. GPIO/ADC/CAN/SPI等外设专用合规器件选型范围；
3. 高低温、工业级、车规级MCU对应的限定物料清单；
4. 禁止跨物料替代场景、不可混用器件组合约束。

### 4. 原理图物料合规校验规则（核心更新wiki/mcu/all/check_rules/）
基于AVL清单生成强制物料校验规则，用于PDF原理图自动审图：
1. 规则1：原理图使用器件料号不在当前生效AVL清单内 → 严重风险，强制拦截；
2. 规则2：物料封装、额定参数与AVL标注不匹配 → 一般风险；
3. 规则3：受限物料未走特殊审批流程 → 优化提醒；
4. 规则4：禁用物料直接使用 → 致命风险；
5. 规则5：未使用AVL推荐物料、随意选用外部替代件 → 优化建议；
每条规则绑定AVL表格溯源，标注风险等级、整改方案、合规物料推荐清单。

### 5. 物料选型故障、兼容性案例（更新wiki/mcu/all/fault_case/）
1. 非AVL物料引发的MCU死机、电源不稳、晶振不起振、ESD损坏等历史故障；
2. 物料混用、参数超限导致的量产失效案例；
3. 记录规避方案：仅使用AVL指定型号、限定替代料使用条件。

### 6. 原理图评审报告物料合规话术（更新wiki/mcu/all/report_template/）
标准化物料不合规描述、风险分级说明、合规整改文案，自动输出物料评审结论。
