# EDA原理图/PCB PDF高精度文字提取AI任务提示词

## 一、任务概述
本任务用于AI自动解析**EDA工具导出的原理图、PCB丝印PDF文件**，精准提取电路标注结构化信息。执行逻辑强制遵循**优先矢量文本解析（方案A），解析失败自动切换专属OCR识别（方案B）**，杜绝通用文档识别逻辑，规避EDA图纸文字轮廓化、小字密集、特殊符号多导致的识别误差，禁止AI脑补、虚构电路信息。

适用工具：Altium Designer、KiCad、Cadence、Fusion360等主流EDA工具导出PDF

提取核心目标：元件位号、元件参数（阻值/容值/型号）、网络标号、电源/地标识、引脚编号、差分/总线特殊标识

非提取范围：电路走线、焊盘、符号图形、边框、网格辅助线，不生成网表、不做电气仿真、不解析电路拓扑

## 二、核心执行规则（强制优先级）
**最高优先级：方案A（无OCR矢量解析）优先执行，检测失效后自动无缝切换方案B，禁止跳过方案A直接使用OCR**

### 2.1 方案A：矢量文本精准解析（首选、最高精度）
#### 2.1.1 适用场景
PDF导出时未开启「文字转轮廓/Text to outlines」，支持鼠标单独选中、复制文字，存在原生矢量文本层。

#### 2.1.2 执行技术规范
- 核心工具：仅使用 **pdfplumber**，禁止使用PyPDF2、原生extract_text简易解析
- 数据读取：必须读取 `page.chars` 完整数据，保留每个字符的文本内容、x0/top坐标、字号、字体属性，**严禁丢弃坐标信息**（坐标为电路关联核心依据）
- 实体筛选：通过EDA专属正则规则精准过滤有效电路信息，过滤无效空白、符号、辅助文字

#### 2.1.3 EDA专属筛选正则规则
- 元件位号：`\b[RCUJLDQTP]\d+\b`（匹配R、C、U、L、D、Q等标准器件位号）
- 器件参数：匹配数字+单位组合，支持k、M、u、n、p、F、V、Ω等电子常用单位，适配阻值、容值、耐压值等参数
- 网络标号：匹配含`_、/、+、-`的工业网络名（例：I2C_SDA、/CS、USB_D+、PLL_OUT）
- 电源地标识：匹配VCC、GND、3V3、5V、1V8等标准电源标识
- 引脚编号：匹配纯数字、数字+字母组合引脚标号

#### 2.1.4 方案A失效判定标准（满足任意1条立即切换方案B）
- pdfplumber读取的chars数据为空或仅有极少无效字符
- PDF文字被强制转为矢量轮廓曲线，无法选中、复制任意文字
- 读取文本出现大量乱码、字符缺失、排版错乱，无有效电路标注信息

### 2.2 方案B：EDA图纸专属OCR识别（兜底方案）
仅在方案A判定失效后执行，**禁止使用通用文档OCR配置**，全程采用电路图纸专属预处理+识别逻辑。

#### 2.2.1 完整执行流水线（固定顺序，不可删减）
PDF文件 → 高清图片渲染 → OpenCV图像预处理 → 图纸分块裁剪 → PaddleOCR专属识别 → 多层规则纠错校验 → 结构化输出

#### 2.2.2 各环节强制规范
1. **高清渲染**：通过pdf2image+poppler渲染，固定DPI为400~600，适配PCB小字丝印、原理图密集标注，禁止默认低DPI渲染
2. **图像预处理**：依次执行灰度化、自适应二值化、底色阴影去除、高斯降噪、细线文字形态学膨胀修复、页面倾斜矫正，彻底解决泛黄、淡印、细线断线问题
3. **分块裁剪**：禁止整图直接识别，对原理图元件区、引脚区、PCB丝印密集区局部裁剪，提升小字识别精度
4. **OCR核心配置**：使用PaddleOCR，开启角度矫正 `use_angle_cls=True`，**禁用通用文档版面布局模型**，加载EDA专属自定义词典
5. **自定义词典内容**：R、C、U、J、L、D、Q、TP、CON、VCC、GND、3V3、5V、10k、0.1uF、+、-、/、_
6. **后置纠错校验**：
    - 形近字强制纠错：l→1、O→0、Ul→U1、VCC3V8→VCC3V3等EDA高频错字替换
    - 正则二次校验所有器件、网络格式，剔除无效乱码
    - 不确定、模糊字符统一标记为【?】，禁止主观脑补补全

## 三、统一输出规范（强制）
### 3.1 输出格式
固定输出**结构化JSON格式**，禁止纯文本杂乱输出、禁止段落式总结。

### 3.2 JSON必填字段
- `page_num`：PDF页码
- `extract_scheme`：本次执行方案（A/B）+ 切换原因（若为B方案必须备注）
- `type`：信息类型（位号/元件参数/网络标号/电源地/引脚号）
- `content`：识别到的原始文字内容
- `x/y`：字符坐标信息（保留原始相对位置）
- `confidence`：识别置信度
- `status`：正常/可疑待复核（格式异常、模糊字符标记）

> JSON示例：
> ```json
> [
>   {
>     "page_num": 1,
>     "extract_scheme": "方案A",
>     "type": "位号",
>     "content": "R1",
>     "x": 120.5,
>     "y": 240.2,
>     "confidence": 1.0,
>     "status": "正常"
>   }
> ]
> ```

### 3.3 禁止行为（严格约束）
- 禁止跳过方案A直接使用OCR识别
- 禁止识别、解析电路图形、走线、焊盘、辅助网格
- 禁止虚构、补全缺失的器件参数、网络标号，杜绝AI幻觉
- 禁止使用通用大模型批量识别，多模态模型仅可用于疑难页人工复核
- 禁止丢弃坐标数据，仅输出纯文本内容

## 四、特殊场景兜底规则
针对老旧EDA图纸、模糊扫描导出PDF、极小丝印图纸：完成基础OCR识别后，仅标记可疑内容，不强制修正；保留所有原始识别结果，优先保证真实性，牺牲部分完整性，杜绝错误修正。
