# 硬件知识库入库调度技能（kb-ingest-dispatch）

## 一、适用场景

当用户要往 `D:\obsidian\硬件知识库`（企业 MCU / 开发板硬件知识库）里**新增**或**更新（增量多版本）**一份资料，并在输入框用自然语言下达，例如：

- `新增 D:\Downloads\SF32LB527_Datasheet_V1.0.pdf`
- `更新 raw/mcu/all_chip/datasheets/UM5201-SF32LB52x-CN.pdf`
- `导入 最小系统原理图 SF32LB52X_MinSys_Sch_V1.0.pdf`
- `把这块开发板原理图入库：DEV-SF32LB527-EVK_Sch_V1.0.pdf`
- `升级 用户手册 到 V3.0`

即触发本技能。覆盖 9 类资料 × 2 种动作 = **18 条**入库指令（MCU 类 14 + 最小系统原理图 2 + 开发板独立大类 2）。

## 二、重要前提（Vault 路径）

- 本技能作用于**当前工作区根目录即知识库 Vault**（默认 `D:\obsidian\硬件知识库`）。所有相对路径以此为基准。
- 若当前工作目录不是该 Vault，先向用户确认 Vault 根目录，再 `cd` 过去。
- 不要改动 `AGENTS_MCU_ALL.md`、`AGENTS_INGEST_MCU.md`、`EDA原理图PDF识别提示词.md` 等规范文件，只读取引用。

## 三、执行流程（严格按序）

1. **解析意图**
   - 动作：含「新增 / 新建 / 导入 / 入库 / 补充 / 建立」→ 新增；含「更新 / 升级 / 迭代 / 新版 / 改版 / 修订 / 增量」→ 更新。
   - 文件类型：从用户给出的文件名 / 路径 / 内容提取关键词（规格书、用户手册、硬件设计指南、开发板使用指南、应用笔记、技术问答、AVL、最小系统原理图、开发板原理图…）。
   - 源文件路径：用户已给完整 / 相对路径则记下；仅给文件名则进入步骤 3。

2. **读取路由表**：读取仓库根目录 `调用指令参考提示词.md`，按其「二、路由表」匹配"文件类型关键词 + 动作"对应的 `cmd/xxx.md` 指令文件。无法判定时，向用户确认是哪种资料。

3. **归置源文件（Raw 存放）**
   - 若源文件已位于该指令的「推荐 raw 位置」（或用户显式给出的 raw 路径），直接读取（Raw 只读：只读取，不修改、不删除源文件）。
   - 若源文件在别处（桌面 / 下载 / 临时目录），将其**复制**（非移动）到路由表「推荐 raw 位置」后再读取，保留原文件不动。
   - 若按文件名找不到文件，列出「推荐 raw 位置」并请用户提供实际路径。

4. **加载并执行指令**：读取匹配到的 `cmd/xxx.md`，严格按其步骤执行：
   - MCU 类 → 写入 `wiki/mcu/all/`，同步 `index_MCU_ALL.md` / `log_MCU_ALL.md`，遵循 `AGENTS_MCU_ALL.md`；
   - 开发板类 → 写入 `wiki/dev_board/all/`，同步 `index_DEVBOARD_ALL.md` / `log_DEVBOARD_ALL.md`；
   - 原理图类（最小系统 / 开发板）→ 先调用 `EDA原理图PDF识别提示词.md` 做 PDF 矢量提取，再拆解。

5. **输出自检**：按该 `cmd/` 指令末尾的「自检清单」输出汇报（新建页 / 更新页 / 冲突待核实 / 新增规则数 / 索引+日志确认 / 双链完整性）。

6. **不编造**：任何模糊、缺失、无法从源文件核实的参数，一律标注「待人工核实」，不臆造；更新类遇冲突分版本留存，不覆盖历史。

## 四、关键强制约定（来自 AGENTS_MCU_ALL.md）

- **Raw 只读**：原始 PDF/表格只读取解析，禁止修改、移动、删除。
- **缺料即停不编造**：描述模糊、缺量化指标的，标记「待人工核实」并暂停，绝不脑补硬件参数。
- **增量补充**：原有 Wiki 页面只追加参考内容，不删除、不覆盖历史规范。
- **模板必填**：所有页面用对应分类 `_template.md`，YAML 元数据必填字段完整。
- **不仿真**：不生成网表、不做电气仿真、不解析走线/焊盘（仅提取文字标注）。

## 六、示例

用户输入：`新增 D:\Downloads\SF32LB527_Datasheet_V1.0.pdf`

技能动作：
1. 解析 → 动作=新增，类型=规格书；
2. 查路由表 → `cmd/新增规格书入库指令.md`，推荐位置 `raw/mcu/all_chip/datasheets/`；
3. 把该 PDF **复制**到 `raw/mcu/all_chip/datasheets/`；
4. 读取并执行 `cmd/新增规格书入库指令.md`（拆解硬件信息 → 建来源页/芯片实体/外设/校验规则 → 更新 index/log）；
5. 输出 6 项自检清单。
