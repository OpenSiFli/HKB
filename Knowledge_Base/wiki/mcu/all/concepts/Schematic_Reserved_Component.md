## 摘要
原理图评审 / 元件提取时，部分器件在图纸上被明确标记为「不焊接 / 不装配」，属预留设计（design reserve）。正确识别这些标记，是避免把预留位误判为「缺件 / 开路 / 违规」的前提。本条约定由 `eda-schematic-review` 技能在提取与出报告时强制采用。

## 核心硬件内容
### 1. 概念定义与工作原理
预留器件（reserved / not mounted）是原理图上**存在位号与封装、但本版本不焊接**的器件，用于：
- 硬件兼容多种配置（如不同屏幕 / 不同传感器 / 不同充电方案）；
- 量产跳线、测试点、EMC 可选电路；
- 设计裕量（料号替代、调试验证位）。

若评审时把它当成「已焊接电路」去对照校验规则，会产生大量**假阳性违规**（误报缺上拉、缺电容、缺 ESD 等）。

### 2. 电气原理与参数
判读只看**图纸标注**，与电气参数无关。任一标记出现即表示不焊接：

| 标记 | 含义 | 说明 |
| --- | --- | --- |
| `DNP` | Do Not Populate / 不焊接 | 最通用，BOM 中列为不贴装 |
| `NC` | No Connect / 不连接 | 亦用于「引脚不连接」；元件标 NC 即不装配 |
| `NF` | Not Fitted / 不安装 | 与 DNP 同义，部分厂商 / 图纸习惯用法 |
| 灰色（立创EDA / LCEDA）| 未放置 / 未启用 | 立创EDA 在原理图或 PCB 中将器件标记为灰色（"不放置"状态），等价于 DNP，不在该版本装配 |

### 3. 设计要点
- **提取阶段**：凡属性含 `DNP` / `NC` / `NF` 或立创EDA 灰色器件，一律按「未装配」处理；建议在 `extract_A.json` 记录 `status: "DNP"` 以便与已焊接器件区分。
- **对照 CR_* 规则时**：若某条规则的被核查对象（如上拉电阻、负载电容、ESD 器件）标 DNP，则该规则对其实例判 **N/A（不适用）**，并在报告中注明「预留不焊」；切勿当作已焊接电路去判定违规或判缺件。
- **实例**：CR_XTAL48M 中 48MHz 晶振两端负载电容标 DNP → 须结合实际料号判断（石英晶体需焊负载电容、陶瓷谐振器可 DNP），不能简单判「缺电容」。
- **注意区分**：`NC` 作为**引脚**标注（某 IC 引脚「不连接」）与作为**元件**标注（整个元件不装配）含义不同，但二者都表示「不焊接 / 不连接」，评审处理一致。

### 4. 规范依据
- 行业通用 BOM / 装配标注惯例（DNP / NC / NF）。
- 立创EDA（LCEDA）器件「不放置 / 灰色」状态语义。
- 项目评审流程：`eda-schematic-review` 技能（步骤1 提取、`references/knowledge_base_review.md` §6）。
